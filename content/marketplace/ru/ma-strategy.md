MaStrategy ищет пересечение быстрой и медленной скользящих средних.

## Как читать график

Быстрая линия раньше реагирует на новые свечи. Пересечение медленной снизу вверх указывает на возможный рост, сверху вниз — на возможное снижение.

<!-- signal-chart -->

## Когда появляется вход

Новое пересечение должно пройти проверки для своего направления. Стратегия может пропустить сигнал, если средние слишком близки, объём слишком мал или цель слишком близка относительно стопа.

## Как закрывается сделка

Стоп и цель заданы отдельно для каждого направления. По умолчанию встречное пересечение может досрочно закрыть лонг. Для шортов это правило выключено.

## Ключи конфигурации

| Группа | Ключи | Назначение |
| --- | --- | --- |
| Стратегия | `MA_FAST`, `MA_SLOW` | Периоды быстрой и медленной средних в свечах. |
| Стратегия | `MA_MIN_CROSS_GAP_ATR_LONG`, `MA_MIN_CROSS_GAP_ATR_SHORT` | Минимальный зазор между средними при входе в единицах ATR для каждой стороны. |
| Стратегия | `LONG.TP`, `SHORT.TP` | Расстояние до цели для соответствующего направления. |
| Стратегия | `LONG.SL`, `SHORT.SL` | Расстояние до стопа для соответствующего направления. |
| Стратегия | `MA_EXIT_ON_OPPOSITE_CROSS_LONG`, `MA_EXIT_ON_OPPOSITE_CROSS_SHORT` | Включает досрочный выход по встречному пересечению для соответствующего направления. |
