AdaptiveTrendChannel следит за направлением цены по верхней и нижней границам канала. Стратегия сглаживает цены свечей и по ним проверяет, удержалось ли прежнее движение.

Стратегия входит в стандартный проект TradeJS. [Как сохранить настройки бэктеста](https://docs.tradejs.dev/ru/getting-started/backtest-config).

## Как читать график

При падении цены верхняя граница проходит над свечами. На схеме видно, как при развороте активная граница перемещается под цену.

## Когда появляется вход

Канал разворачивается вверх, когда сглаженные минимумы и цена закрытия проходят свои уровни сопротивления. Для разворота вниз стратегия проверяет соответствующие уровни поддержки. По умолчанию для лонга нужен пробой минимум на 1,2 ATR, для шорта — на 0,9 ATR. ATR показывает типичный размер движения цены. Если настроено дополнительное подтверждение, новое направление должно сохраниться заданное число свечей.

Для лонга новая нижняя граница задаёт начальный стоп. Для шорта эту роль играет новая верхняя граница. По умолчанию расстояние от входа до цели вдвое больше расстояния до стопа. Чем дальше стоп, тем меньше объём позиции при одинаковом лимите убытка.

## Как закрывается сделка

В плане сделки уже есть начальный стоп и цель. После входа стратегия дополнительно проверяет два условия: закрылась ли свеча за действующей границей канала против позиции и подтвердился ли встречный сигнал. Действующая граница может сдвинуться относительно начального стопа. Поэтому стратегия может запросить закрытие раньше, чем цена дойдёт до этого стопа.

<!-- channel-exits -->

При нулевом подтверждении выхода достаточно свечи сигнала. Если указана одна свеча или больше, пробой или встречное направление канала должны сохраняться на этих дополнительных закрытых свечах. Если оба условия сработали на одной свече, приоритет у пробоя границы.

## Ключи конфигурации

| Группа | Ключи | Назначение |
| --- | --- | --- |
| Канал | `ADAPTIVE_TREND_CHANNEL_REGRESSION_BARS` | Число свечей для расчёта направления и наклона канала. |
| Канал | `ADAPTIVE_TREND_CHANNEL_ENVELOPE_BARS` | Сколько последних значений регрессии берут для определения верхней и нижней границы. |
| Канал | `ADAPTIVE_TREND_CHANNEL_ATR_STRETCH` | Во сколько раз расширяется полоса вокруг средней линии с учётом волатильности. |
| Канал | `ADAPTIVE_TREND_CHANNEL_VOLATILITY_LOOKBACK` | Число свечей для расчёта ATR, меры волатильности канала. |
| Канал | `ADAPTIVE_TREND_CHANNEL_MIN_CHANNEL_WIDTH_PCT` | Отклоняет сигнал, если канал уже этого порога в процентах. Ноль отключает проверку. |
| Канал | `ADAPTIVE_TREND_CHANNEL_MAX_CHANNEL_WIDTH_PCT` | Отклоняет сигнал, если канал шире этого порога в процентах. Ноль отключает проверку. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MIN_BREAKOUT_DISTANCE_PCT` | Минимальное расстояние от средней линии канала в процентах. Ноль отключает проверку. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MAX_BREAKOUT_DISTANCE_PCT` | Максимальное расстояние от средней линии канала в процентах. Ноль отключает проверку. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MIN_BREAKOUT_DISTANCE_ATR` | Минимальное расстояние от средней линии канала в единицах ATR. Настройка для стороны имеет приоритет. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MIN_BREAKOUT_DISTANCE_ATR_LONG` | Минимальное расстояние пробоя для лонга в единицах ATR. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MIN_BREAKOUT_DISTANCE_ATR_SHORT` | Минимальное расстояние пробоя для шорта в единицах ATR. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MAX_BREAKOUT_DISTANCE_ATR` | Максимальное расстояние пробоя в единицах ATR. Ноль отключает проверку. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MIN_VOLUME_REL20` | Минимальный объём относительно среднего за 20 свечей. Ноль отключает проверку. |
| Вход | `ADAPTIVE_TREND_CHANNEL_REQUIRE_CONTEXT_ALIGNMENT` | Включает проверку, согласуется ли направление сигнала с состоянием рынка. |
| Вход | `ADAPTIVE_TREND_CHANNEL_MIN_CONTEXT_ALIGNMENTS` | Сколько признаков должны подтверждать направление, если проверка контекста включена. Среди них тренд, локальный диапазон и движение ориентира. |
| Вход | `ADAPTIVE_TREND_CHANNEL_FLIP_CONFIRMATION_BARS` | Сколько дополнительных свечей должно продержаться новое направление перед входом. |
| Вход | `ADAPTIVE_TREND_CHANNEL_REQUIRE_PRICE_ACCEPTANCE` | Требует закрытия выше недавнего максимума для лонга или ниже недавнего минимума для шорта. |
| Выход и риск | `ADAPTIVE_TREND_CHANNEL_TARGET_R_MULT` | Расстояние от входа до цели в долях расстояния от входа до стопа. |
| Выход и риск | `ADAPTIVE_TREND_CHANNEL_EXIT_ON_CHANNEL_BREAK` | Запрашивает закрытие, если свеча закрылась на активной границе или за ней против позиции. |
| Выход и риск | `ADAPTIVE_TREND_CHANNEL_EXIT_ON_OPPOSITE_FLIP` | Запрашивает закрытие при подтверждённой смене направления против позиции. |
| Выход и риск | `ADAPTIVE_TREND_CHANNEL_EXIT_CONFIRMATION_BARS` | Сколько дополнительных свечей должно сохраняться условие выхода. При нуле достаточно свечи сигнала. |
| Выход и риск | `ADAPTIVE_TREND_CHANNEL_EXIT_CONFIRMATION_BARS_LONG` | Подтверждение выхода для лонга. Если значение не задано, действует общая настройка. |
| Выход и риск | `ADAPTIVE_TREND_CHANNEL_EXIT_CONFIRMATION_BARS_SHORT` | Подтверждение выхода для шорта. Если значение не задано, действует общая настройка. |
| Выход и риск | `ADAPTIVE_TREND_CHANNEL_REENTRY_COOLDOWN_MS` | Минимальная пауза между сигналами входа в миллисекундах. Значение по умолчанию равно 24 часам. |
| Выход и риск | `MAX_LOSS_VALUE` | Лимит убытка для расчёта размера позиции с учётом стопа и оценочных издержек. |
| Выход и риск | `LONG.enable`, `SHORT.enable` | Разрешает входы для соответствующего направления. |
| Выход и риск | `LONG.minRiskRatio`, `SHORT.minRiskRatio` | Минимальное отношение цели к риску для каждого направления с учётом оценочных издержек. |
| Свечи и график | `INTERVAL` | Интервал свечей, на которых стратегия оценивает сигналы. |
| Свечи и график | `ADAPTIVE_TREND_CHANNEL_MAX_FIGURE_POINTS` | Максимальное число точек, которые сохраняются для отрисовки канала. |
