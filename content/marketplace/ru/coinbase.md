Адаптер Coinbase загружает публичные свечи и цены спотового рынка для бэктестов и расчётов стратегий.

## Рынок и возможности

Укажите инструмент в формате TradeJS, например `BTCUSDT`. Адаптер запросит пару `BTC-USD`, поэтому цены будут в долларах США. Учитывайте это при сравнении результатов с другими биржами. Отправка ордеров через адаптер недоступна.

## Ключи конфигурации

В столбце со значениями по умолчанию указан состав стандартного проекта с `basePreset`.

| Ключ | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `connectors` | `["@tradejs/connectors"]` | Подключает пакет адаптеров в `tradejs.config.ts`. |
| `COINBASE_BASE_URL` | `https://api.exchange.coinbase.com` | Позволяет переопределить адрес публичного API Coinbase через переменную окружения проекта. |
